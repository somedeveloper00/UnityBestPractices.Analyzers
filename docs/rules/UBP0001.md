# UBP0001: Encapsulate serialized field

| Property | Value |
| --- | --- |
| Rule ID | `UBP0001` |
| Category | `Unity.API.Design` |
| Default severity | `Info` |
| Safety classification | `ReviewRequired` |
| Fix All | Not supported |

## Summary

A private field with SerializeField preserves Inspector serialization without exposing mutable state as public API.

> Review the resulting code and test its runtime behavior before committing it.

## Why the rule exists

The recognized form is `A serializable public field on a \`MonoBehaviour\` or \`ScriptableObject\``. The quick fix uses `Adds \`[UnityEngine.SerializeField]\` and makes the field private` to express the documented Unity or C# best practice while retaining the rule's semantic preconditions.

## Exact applicability constraints

- The compiler must resolve every required API to the expected symbol rather than a same-named look-alike.
- Required symbols: `UnityEngine.MonoBehaviour`, `UnityEngine.ScriptableObject`, `UnityEngine.SerializeField`
- The syntax must match the conservative shape documented in the summary and must pass the rule's semantic guards.
- The analyzer excludes generated code and remains silent when required Unity or package symbols are unavailable.
- The quick fix is offered only when it can construct a complete local transformation.
- Before registering the fix, solution-wide symbol reference analysis must prove that every reference is inside the declaring type or one of its nested types.

## Known exclusions

- Dynamic dispatch, unresolved overloads, malformed syntax, and same-named user APIs are excluded.
- Cases requiring whole-program behavioral inference are excluded.
- More complex but potentially equivalent source shapes may intentionally receive no suggestion.
- The diagnostic remains visible, but the fix is withheld when a derived type, unrelated type, `nameof`, or any other external solution reference would lose access.

## Fix All support

No. Apply this quick fix to one occurrence at a time.

## Required Unity or package version

Unity 2021.3. Availability is additionally determined from the required symbols in the active compilation.
