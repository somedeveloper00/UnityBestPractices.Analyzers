# UBP0072: Dispose persistent native container

| Property | Value |
| --- | --- |
| Rule ID | `UBP0072` |
| Category | `Unity.Correctness` |
| Default severity | `Info` |
| Safety classification | `Safe` |
| Fix All | Not supported |

## Summary

A locally owned persistent NativeArray must be disposed or transfer ownership before the method exits.

## Why the rule exists

The recognized form is `A locally owned \`NativeArray<T>\` allocated with \`Allocator.Persistent\` and undisposed on every analyzed exit`. The rule is diagnostic-only because choosing the correct ownership or lifetime requires application context.

## Exact applicability constraints

- The compiler must resolve every required API to the expected symbol rather than a same-named look-alike.
- Required symbols: `Unity.Collections.NativeArray`1`, `Unity.Collections.Allocator`
- The syntax must match the conservative shape documented in the summary and must pass the rule's semantic guards.
- The analyzer excludes generated code and remains silent when required Unity or package symbols are unavailable.
- No code action is registered for this diagnostic.
- The allocation must be a directly constructed local `NativeArray<T>` using `Allocator.Persistent` in a block-bodied method, constructor, or local function, and Roslyn control flow must prove that every reachable exit retains ownership without disposal.

## Known exclusions

- Dynamic dispatch, unresolved overloads, malformed syntax, and same-named user APIs are excluded.
- Cases requiring whole-program behavioral inference are excluded.
- More complex but potentially equivalent source shapes may intentionally receive no suggestion.
- The analyzer remains silent if any reachable exit disposes or transfers ownership, and for unsupported bodies. `Dispose()`, `using` declarations, and `using` statements are recognized disposal forms. Ordinary reads, element writes, and calls to unconfigured methods are non-owning uses. Returns and field/property assignments transfer ownership; configured invocation sinks use `ubp_0072_ownership_transfer_methods` with comma- or semicolon-separated method names or documentation IDs.

## Fix All support

Not applicable. This rule is diagnostic-only.

## Required Unity or package version

Unity 2021.3 with Collections 1.x. Availability is additionally determined from the required symbols in the active compilation.
