# UBP0076: Set local position and rotation together

## Summary

Combine adjacent assignments to `Transform.localPosition` and `Transform.localRotation` by calling
`Transform.SetLocalPositionAndRotation` once.

## Why this matters

The combined Unity API updates both values in one native call rather than crossing the managed/native
boundary for each property assignment.

## Fix

```csharp
transform.SetLocalPositionAndRotation(position, rotation);
```
